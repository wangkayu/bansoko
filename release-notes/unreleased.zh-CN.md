## 新增

- 字幕组支持「合并集发布」设置（每集包含集数 1 到 12，默认 1）：单个单集编号的发布文件自动展开为连续集数范围，例如每集包含 2 集时第 2 集发布对应第 3-4 集；RSS 预览、订阅评价、洗版比较、命名与入库覆盖均按展开后的范围计算，偏移对每个包含集各应用一次。设置折叠在偏移对话框中，需要时展开；文件名已显式标注范围（如 E01-E02）时不重复展开。
- 一次性下载与文件管理器识别支持逐文件集数范围：集数输入接受 1-2 形式（连续、最多 12 集），用于一个视频包含多集的合并集发布；目标文件名渲染为 S01E01-E02，绑定字幕继承同一编号，入库记录覆盖全部包含集数，洗版比较多集单元规则不变。顺序填充新增「每文件集数」，可将勾选项连续填为 1-2、3-4、5-6。
- qBittorrent 下载器连接支持选择认证方式：沿用用户名和密码登录，或使用 qBittorrent 5.2 及以上版本提供的 API 密钥无状态认证；同时兼容 qBittorrent 5.2 登录返回的 204 成功响应。
- API 令牌与 MCP 新增第四级「管理（admin）」权限（默认不勾选），用于隔离删除操作、文件管理根目录配置、系统与解析器更新及事件脚本写入等高风险动作；隐藏的命名变量功能继续不对 MCP 开放。
- MCP 新增文件管理只读/写入与事件脚本、更新相关工具，并按令牌权限尊重「显示敏感值（secrets）」：持有该权限的令牌可通过 MCP 读回敏感字段原值，未持有时保持脱敏。
- 版本比较（洗版）新增文件大小比较项（file.size）与字幕封装类型未知项（unknown），支持在偏好列表中自由排序。

## 改进

- API 的 JSON 响应支持 gzip 压缩协商：客户端声明 Accept-Encoding 时自动压缩较大响应，显著降低弱网链路上的传输体积；实时事件流（SSE）与文件下载不受影响。
- 重设计版本比较编辑器，支持直接添加、排序与管理各维度的优先级及取值顺序。
- 优化番剧配置弹窗四个页签（元数据、字幕组、规则、RSS）的交互与布局：元数据页签分组展示属性、解绑 TMDB 前提示确认并拦截非法数值输入；字幕组页签统一顶部操作栏并在刷新前保护未保存修改；规则页签支持折叠区块与实时正则校验；RSS 页签在预览模式下保持「显示被过滤」可用，并统一草稿与已订阅预览流。

## 修复

- 修复已添加 Jackett 连接后仍可在「新建连接」中重复添加 Jackett 的问题，后端与界面均限制仅保留单个 Jackett 连接并引导直接编辑已有连接。
