## 改进

- 应用更新改为服务连接中的一个 GitHub 连接：更新请求的地址可在「更新地址」里改成自己的反向代理，出口则从「网络代理」中选择，代理地址和凭据只需在「网络代理」中维护一处。地址默认官方地址，保存后下一次更新生效；停用该连接或停用所选代理时，更新回到官方地址直连。「测试」会按当前地址和代理读取更新频道，结果显示在行内。
- 一次性下载选择种子时，勾选只在当前字幕组内有效：切换到其他字幕组后，之前的勾选不再保留，已选数量从零开始，返回已进入过的组时也不会恢复。
- 第 0 季的文件夹现在命名为 Specials，完整路径为 /Specials。已入库的文件保持原来的名称，只有新入库的文件使用 Specials。
- 所有者密码的最短长度改为 8 个字符。
- 下载因超时失败时（超过无进度时限或最长下载时间），现在会删除下载器中的任务和文件；这次下载之前就已存在的任务和其他原因的失败仍保留任务，方便重试。
- 字幕组名单和名称评分的添加规则改为在对话框里编辑，移动端也能使用；打开字幕组名单对话框即可浏览、筛选名称词典并直接选择。
