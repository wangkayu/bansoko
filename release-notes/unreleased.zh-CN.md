## 改进

- 服务连接中的「应用更新」作为连接列表的最后一行：从「网络代理」中选择一项，作为应用更新访问 GitHub 的出口；代理地址和凭据只需在「网络代理」中维护一处。这一行显示当前出口，点「编辑」在弹窗中选择并保存后生效；不选或所选代理已停用时跟随部署默认。
- 一次性下载选择种子时，勾选只在当前字幕组内有效：切换到其他字幕组后，之前的勾选不再保留，已选数量从零开始，返回已进入过的组时也不会恢复。
- 第 0 季的文件夹现在命名为 Specials，完整路径为 /Specials。已入库的文件保持原来的名称，只有新入库的文件使用 Specials。
- 所有者密码的最短长度改为 8 个字符。
