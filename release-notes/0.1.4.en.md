## Improved

- Naming templates now use the recommended spellings: short roots (a., r., f., sub., ep., t., tmdb.) and the usual whole-value names (${n}, ${y}, ${s00e00}, ${group}, ${langtag} and others). The editor no longer lists both the long and the short form of the same field, or a few fields kept only for older templates; saved templates are rewritten to the recommended spelling on update. A few old spellings are no longer accepted: file.rt.*, rt.subgroup, frt.subgroup, tmdb.original_title and bare ${ep}.
- Releases that failed only because metadata was missing a naming fact are re-evaluated automatically once the metadata supplies it, instead of needing a manual retry for each one.
- File-manager recognition now keeps Load metadata and Set file numbering in a toolbar above the plan rows; the settings column holds fields only, and the load state and manual-override count show beside their buttons.

## Fixed

- After replacing a metadata binding, title suggestions no longer include entries from the previous binding.
